How to watch a downloaded demo?

  1. Download the .dem file using the link below.
  2. Move the file into your game directory (usually ...\csgo\).
  3. Launch CS:GO, open developer console, and type: playdemo file_name
  4. Press Shift + F2 to open the demo playback control panel.
